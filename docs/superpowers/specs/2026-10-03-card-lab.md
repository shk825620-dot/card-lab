# card-lab（卡片工坊）需求规格

## 目标

做一个纯前端、零后端、零服务器的网页工具：用户输入文字，页面实时预览一张排版精美的卡片，并可一键导出 PNG 图片。桌面端与手机端浏览器打开同一个网址即可使用。

项目的另一层目标：这是作者在 GitHub 上的第一个开源作品，需要靠"一眼看得懂的好看效果"获得 100 颗真实 star，因此演示物料（README 演示 GIF）与代码同等重要。

## 首版范围

- 单页应用，无需登录、无账号体系、无网络请求。
- 输入：主标题文字、副标题文字（可空）。
- 4 套模板：`glass`（渐变暗色 + 玻璃拟态）、`neon`（霓虹赛博）、`zen`（日系极简）、`magazine`（杂志排版）。
- 每套模板内提供若干预设配色，不支持自定义调色盘。
- 4 种画布尺寸：`square` 1080×1080、`portrait` 1080×1440、`story` 1080×1920、`wide` 1920×1080。
- 字号滑杆（`fontScale`）在主标题基础上整体缩放。
- 导出 PNG：默认 2 倍像素密度（`pixelRatio: 2`），文件名形如 `card-lab-2026-10-03-1612-square.png`。
- 预览自适应：卡片按逻辑尺寸渲染，用 `transform: scale()` 适配容器，保证所见即所得。
- 纯前端零依赖可运行：即使不安装任何 npm 包，`index.html` 也能通过本地静态服务器直接运行。
- 本地开发提供两条命令：`npm run dev`（Vite + HMR）与 `node server.mjs`（零依赖兜底）。
- 部署到 GitHub Pages，通过 GitHub Actions 自动构建发布。

## 暂不纳入

- 用户登录、云端保存、分享链接、历史记录。
- 自定义字体上传、自由配色盘、图层编辑、贴纸素材。
- 任何后端服务、数据库、对象存储。
- 多语言界面（首版仅中文）。
- 购买或交换 star 等作弊手段；推广渠道的发帖动作由作者人工执行。

## 硬约束

1. **零后端**：不得引入任何需要服务器、API Key 或付费服务的功能。
2. **导出兼容性**：导出依赖 `modern-screenshot`（DOM → SVG `foreignObject` → PNG），该路径**不支持 `backdrop-filter`**。因此玻璃拟态效果必须用半透明渐变 + 内阴影近似实现，全项目禁用 `backdrop-filter`。
3. **子路径部署**：GitHub Pages 地址形如 `https://<user>.github.io/card-lab/`，Vite 必须配置 `base: './'`，所有资源使用相对路径。
4. **零注入风险**：所有用户文字一律通过 `textContent` 写入 DOM，禁止 `innerHTML`。
5. **测试可离线运行**：单元测试使用 Node 内置 `node:test`，不依赖需要下载的原生插件。

## 后续扩展

- 导出倍率开关（1x / 2x / 3x）与 PNG/JPG 双格式。
- 卡片内容分页、批量导出。
- 保存自定义配色为主题（localStorage）。
- 英文界面与国际化。

## 验收标准

1. `node tests/<每个测试文件>` 全部通过。
2. `node server.mjs` 启动后，首页返回 200 且包含 `#card`、`#export-btn`。
3. 4 套模板 × 4 种尺寸均可正常预览与导出，导出的 PNG 非空且像素尺寸等于逻辑尺寸 × 2。
4. 桌面 1440px 宽与手机 375px 宽下布局均不出现横向滚动、控件可点击。
5. GitHub Pages 公网地址返回 200，手机上可打开并成功导出图片。
