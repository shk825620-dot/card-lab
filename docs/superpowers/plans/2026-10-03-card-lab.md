# card-lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a zero-backend, phone-friendly web tool that turns typed text into a beautiful card and exports it as a PNG.

**Architecture:** A single static page built from plain ES modules. `store.js` is the only mutable state holder; `model.js`, `theme.js`, `fit.js` and `filename.js` stay pure so they can be unit-tested with Node's built-in test runner. Templates are data-driven: each template is a token object compiled into CSS custom properties on the card element, so adding a template means adding a token set plus a CSS block. Export uses a vendored UMD build of `modern-screenshot` and therefore must avoid `backdrop-filter`.

**Tech Stack:** Node v24.19.0, npm 11.17.0, Vite 7 (dev server + build), `node:test` + `node:assert/strict` (offline unit tests), plain CSS, `modern-screenshot` 4.7.0 (vendored UMD).

**Spec:** `docs/superpowers/specs/2026-10-03-card-lab.md`

## Global Constraints

- No backend, no API keys, no paid services, no network requests at runtime.
- `backdrop-filter` is forbidden anywhere in the project; approximate glass with translucent gradients plus inset shadows.
- `vite.config.js` must set `base: './'` so GitHub Pages sub-path hosting works.
- All user text reaches the DOM through `textContent`; `innerHTML` is forbidden for user content.
- Unit tests must run with `node tests/<file>` directly (no native addons, no `node --test`).
- Export must produce a PNG whose pixel size equals logical card size times `pixelRatio`.

## Environment Constraints (measured, not assumed)

- The sandbox blocks PowerShell `Invoke-WebRequest` (TLS failure), but Node `fetch` reaches npm registry, jsDelivr and api.github.com with HTTP 200.
- `npm` needs a writable cache directory: use `$env:npm_config_cache = 'C:\Users\KSH\Desktop\k\.npm-cache-probe'`.
- `npm install` must run with `--ignore-scripts` in this sandbox (lifecycle scripts cannot spawn).
- `vite build` fails with `spawn EPERM` inside this sandbox because Vite calls `exec('net use')` on Windows. It is expected to work on a normal machine and in GitHub Actions.
- `node --test` fails with `spawn EPERM` in this sandbox; run test files directly instead.
